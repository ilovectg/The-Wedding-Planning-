# 🌸 The Best Wedding Planning Services

একটি সম্পূর্ণ **Wedding Planning Website** যেখানে ব্যবহারকারীরা সহজেই তাদের বিবাহের পরিকল্পনা করতে পারবেন।

---

## 📋 Project Overview

এই প্রজেক্টে রয়েছে:
- ✅ **User Registration & Login** - Email verification সহ
- ✅ **Wedding Packages** - Silver, Gold, Premium
- ✅ **Venue Booking** - সব ভেন্যুর তালিকা ও উপলব্ধতা
- ✅ **Budget Calculator** - স্মার্ট বাজেট পরামর্শ
- ✅ **Event Services** - Catering, Decoration, Photography, etc.
- ✅ **Admin Dashboard** - সম্পূর্ণ ম্যানেজমেন্ট
- ✅ **Payment Gateway** - Bkash, Nagad, Card
- ✅ **Review & Rating System**
- ✅ **Wishlist/Favorites**
- ✅ **Notification System**

## 📁 Database Tables

13টি প্রধান টেবিল:
1. **users** - ব্যবহারকারী তথ্য
2. **packages** - বিবাহ প্যাকেজ
3. **venues** - ভেন্যু তালিকা
4. **services** - ইভেন্ট সেবা
5. **bookings** - বুকিং রেকর্ড
6. **payments** - পেমেন্ট তথ্য
7. **gallery** - ছবি ও ভিডিও
8. **reviews** - রেটিং ও মতামত
9. **wishlist** - পছন্দের তালিকা
10. **notifications** - বিজ্ঞপ্তি
11. **decoration_themes** - ডেকোরেশন থিম
12. **booking_services** - বুকিং সেবা সম্পর্ক
13. **admin_logs** - এডমিন কার্যকলাপ

## 🚀 শুরু করা

### 1. ডাটাবেস সেটআপ
```bash
mysql -u root -p
source database/schema.sql
```

### 2. ব্যাকএন্ড সেটআপ
```bash
cd backend
npm install
npm start
```

### 3. ফ্রন্টএন্ড
ব্রাউজারে খুলুন: `frontend/index.html`
